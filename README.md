## Installation

### Quick Run (No installation required)
If you just want to try it out:
\`\`\`bash
bash <(curl -sSL https://raw.githubusercontent.com/imsoroban/tuxfetch/main/tuxfetch)
\`\`\`

### Permanent Installation
To install `tuxfetch` globally on your system:
\`\`\`bash
curl -sSL https://raw.githubusercontent.com/imsoroban/tuxfetch/main/install.sh | bash
\`\`\`
